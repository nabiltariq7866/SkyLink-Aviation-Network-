# SkyLink Demo Acceptance Flow

Use this sequence for the client walkthrough. The application uses synthetic local data and simulates production integrations.

1. Switch between Broker and Super Admin from the role dropdown.
2. Open Aircraft Marketplace and create a new aircraft.
3. Open the created aircraft detail route.
4. Change its availability status. Requirements are recalculated and availability/match alerts are written to the audit stream.
5. Open Buyer Requirements and create an anonymous sourcing mandate.
6. Open the requirement detail page and review ranked matches and explanations.
7. Shortlist aircraft, then open Aircraft Comparison.
8. Generate and save the client-ready sourcing summary.
9. Open the selected aircraft and create a Deal Room. The best-fit requirement is linked automatically.
10. Open the Deal Room and progress stages toward NDA, LOI, Negotiation and Closed.
11. Invite a participant and add a transaction document.
12. Open Documents & Disclosure, submit Level 3 access, switch to Super Admin or Compliance Admin, and approve it.
13. Open Secure Messaging, send a message, share an aircraft card and attach a document.
14. Open Opportunity Alerts and review the generated match/status alerts.
15. Open Security & Audit to see the actions recorded in the audit trail.
16. Open Reports and generate a report. Open it in the secure viewer or export the synthetic text report.
17. Use Search & Discovery to search across aircraft, brokers, requirements and deals, then save a search.
18. Open Governance, run a quality scan, review an item, and approve/return it.
19. Open Integrations, add a connector, then run its connection test.
20. Reset Demo Data from Settings when you want the original seeded state again.
